# Smart Household Food Inventory Management System

### ระบบบริหารจัดการวัตถุดิบอาหารอัจฉริยะสำหรับครัวเรือนเพื่อลดอาหารเหลือทิ้ง

โมบายแอปพลิเคชันช่วยครัวเรือน **บันทึก–ติดตาม–วางแผน** การใช้วัตถุดิบอาหารอย่างเป็นระบบ
แจ้งเตือนก่อนหมดอายุ แนะนำเมนูจากของที่มี และวิเคราะห์พฤติกรรมการทิ้งอาหาร
เพื่อ **ลดปริมาณอาหารเหลือทิ้ง** และ **ลดค่าใช้จ่ายในครัวเรือน**

> ผู้จัดทำ: นางสาวสิรารมย์ ชุ่มกระแสร์ (660710629)

##  ที่มาของโครงงาน

องค์การอาหารและเกษตรแห่งสหประชาชาติ (FAO) ประมาณการว่าอาหารที่ผลิตเพื่อบริโภคทั่วโลก
ราวหนึ่งในสามถูกทิ้งโดยเปล่าประโยชน์ และรายงาน *Food Waste Index 2021* ระบุว่า **61%**
ของขยะอาหารทั่วโลกเกิดจาก **ภาคครัวเรือน**

สาเหตุสำคัญคือผู้บริโภค **ไม่สามารถติดตามวัตถุดิบที่มีอยู่** โดยเฉพาะวันหมดอายุ ทำให้ซื้อซ้ำซ้อน
เก็บไม่เหมาะสม และปล่อยของหมดอายุก่อนใช้ ระบบนี้จึงถูกพัฒนาขึ้นเพื่อแก้ปัญหาดังกล่าวในระดับครัวเรือน

##  ฟีเจอร์หลัก

| # | ฟีเจอร์ | รายละเอียด |
|---|---------|-----------|
| 1 |  **จัดการบัญชีผู้ใช้** | สมัครสมาชิก เข้าสู่ระบบ แก้ไขข้อมูลส่วนตัว โดยข้อมูลของแต่ละคนแยกจากกัน |
| 2 |  **จัดการวัตถุดิบ** | เพิ่ม แก้ไข ลบ ค้นหา — เก็บชื่อ ประเภท จำนวน และวันหมดอายุ |
| 3 |  **อ่านวันหมดอายุด้วย OCR** | ถ่ายภาพฉลาก → EasyOCR อ่านข้อความ → ดึงวันหมดอายุอัตโนมัติ (ตรวจสอบ/แก้ไขก่อนบันทึกได้) |
| 4 |  **ติดตามและแจ้งเตือน** | คำนวณวันคงเหลือ แสดงสถานะสี 🟢 ปกติ / 🟡 ใกล้หมดอายุ / 🔴 หมดอายุ + Push Notification |
| 5 |  **แนะนำเมนูอาหาร** | แนะนำเมนูจากวัตถุดิบที่มี โดย **จัดลำดับของที่ใกล้หมดอายุก่อน** |
| 6 |  **วิเคราะห์อาหารเหลือทิ้ง** | บันทึก/สรุปจำนวน ประเภท สาเหตุ และแนวโน้มการทิ้ง แสดงผลเป็น Dashboard |

##  เทคโนโลยีที่ใช้

**ฝั่งแอปพลิเคชัน (Mobile)**
- `Dart` + `Flutter` — พัฒนา UI แบบ cross-platform
- `fl_chart` — กราฟบน Dashboard
- `Firebase Cloud Messaging` — Push Notification

**ฝั่งเซิร์ฟเวอร์ (Backend)**
- `Python` + `Flask` — REST API
- `EasyOCR` — อ่านตัวอักษรจากภาพฉลาก
- `OpenCV` — ปรับภาพก่อน OCR (grayscale, ลด noise)
- `MySQL` — ฐานข้อมูลหลัก

**เครื่องมือพัฒนา**
- Visual Studio Code, Android Studio

**สิ่งที่ต้องมี:** Flutter SDK `>=3.3` และอุปกรณ์ Android / emulator

```bash

flutter pub get
```

##  รายละเอียดหน้าจอ

| หน้าจอ | หน้าที่ | ตรงกับขอบเขต |
|--------|--------|-------------|
| **Login / Register** | เข้าสู่ระบบและสมัครสมาชิก | 1 |
| **Dashboard** | สรุปจำนวนวัตถุดิบ ใกล้หมดอายุ หมดอายุ + กราฟวงกลม/เส้น | 6 |
| **Inventory** | รายการวัตถุดิบ ค้นหา กรองตามสถานะ เรียงตามวันหมดอายุ | 2, 4 |
| **Add / Edit** | ฟอร์มเพิ่มวัตถุดิบ เลือกประเภท จำนวน วันหมดอายุ | 2 |
| **Scan OCR** | จำลองการถ่ายภาพฉลากและแสดงผลที่อ่านได้ | 3 |
| **Recipe** | เมนูแนะนำ เรียงตามวัตถุดิบใกล้หมดอายุก่อน | 5 |
| **Waste Analysis** | กราฟแท่งรายเดือน สาเหตุการทิ้ง และปุ่มบันทึก | 6 |
| **Profile** | ข้อมูลผู้ใช้ ตั้งค่าการแจ้งเตือน ออกจากระบบ | 1 |

**กติกาสถานะสี** (คำนวณใน `models/ingredient.dart`)
- 🟢 **ปกติ** — เหลือมากกว่า 3 วัน
- 🟡 **ใกล้หมดอายุ** — เหลือ 0–3 วัน
- 🔴 **หมดอายุแล้ว** — เลยวันหมดอายุ

##  สิ่งที่ต้องต่อยอด

1. **เชื่อม Backend** — แทนที่ `sample_data.dart` ด้วยการเรียก Flask REST API + MySQL
2. **กล้อง + OCR จริง** — ใช้แพ็กเกจ `image_picker` / `camera` ส่งภาพให้ EasyOCR + OpenCV
3. **แจ้งเตือน** — ตั้งค่า Firebase Cloud Messaging สำหรับแจ้งเตือนวัตถุดิบใกล้หมดอายุ
4. **ระบบแนะนำเมนู** — พัฒนา algorithm จับคู่วัตถุดิบกับฐานข้อมูลเมนู
